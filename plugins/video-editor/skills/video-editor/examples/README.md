# Examples

Two worked clips that produced the animation rules in `references/animation-2-5d.md`.

| Folder | Clip | User score |
|---|---|---|
| `roro-jonggrang/` | Javanese legend, 2.5D photo collage (v3 compositor + synthesized mood SFX) | 8/10 |
| `pompeii-casts/` | Pompeii plaster casts, built with the v4 rules (sub-shots, real time-lapse, cavity diagram, whip pans, real SFX) | 9.5/10 |

Media is **not** included. The scripts expect:
- photos / footage / sounds downloaded from Wikimedia Commons (lists with authors and licences: `PHOTO_CREDITS.md`, `ASSET_CREDITS.md`), cut out with `rembg` into `cut/`;
- a narration track you have the right to use (the test clips used a YouTube creator's narration for local testing only; it is not redistributed here), plus its subtitle timing.

Rendered demo videos without the narration are in the repository's `demos/` folder.
